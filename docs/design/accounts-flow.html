Runic · accounts, phase 2

How a second login flows through Runic

  • The default account's id equals the provider's raw value, so one-login installs change nothing on disk.
  • An added account carries a config directory; the fetch runs with that directory in its environment, so the vendor's own credential location is read.
  • Until the menu grows account tabs, diagnostics/accounts.json is where a second login is seen to land.
